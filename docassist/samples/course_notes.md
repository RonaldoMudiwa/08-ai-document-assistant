## Classes and objects

A class is a blueprint for making objects. An object is one thing made from that blueprint. For example, a Car class could make many car objects, each with its own colour and mileage.

Inheritance lets one class take on the features of another. A SavingsAccount class can inherit from an Account class and add an interest rate.

## Testing

Unit tests check one small piece of code at a time. In Python we write them with pytest. A test should check one behaviour and have a clear name.
